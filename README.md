# tsfm-solar-2
Domain adaptation of time-series foundation models for minute-scale solar irradiance forecasting

## Example and verification data

The repository includes processed QIQ station data in `Data/bsrn_1min/qiq/`
and the prepared forecast inputs in `Data/forecast_input/holdout_all.npz`.
See [Data/README.md](Data/README.md) for the array schema, units, and verification years.
